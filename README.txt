PUNJAB AUTO STORES — HTML/CSS/JS WEBSITE

Pages
- index.html      Home
- shop.html       Searchable/filterable 14-product catalog
- product.html    Dynamic product detail page (?id=...)
- brands.html     Brand portfolio
- about.html      Company story, mission, vision, CEO message
- contact.html    Contact + WhatsApp inquiry form

Assets
- assets/logo.webp    Provided Punjab Auto Stores logo
- assets/styles.css   Full responsive design
- assets/app.js       Product data, catalog filters, product details, mobile nav, form behavior

How to run
1. Extract the ZIP.
2. Open index.html in a browser, or upload the entire folder to hosting.
3. For best results on hosting, keep the same folder structure.

Notes
- Product names/specifications and business information were adapted from the current Punjab Auto Stores website.
- The design uses the gold/black/silver direction from the supplied logo.
- Product-card visuals are stylized metallic part graphics; hero/about background imagery references existing Punjab Auto Stores web assets.
- The inquiry form is front-end only and opens WhatsApp, so no backend is required.
